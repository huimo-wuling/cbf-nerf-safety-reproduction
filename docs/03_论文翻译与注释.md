## 摘要（Abstract）

**【原文】**
To navigate complex environments, robots must increasingly use high-dimensional visual feedback (e.g. images) for control. However, relying on high-dimensional image data to make control decisions raises important questions; particularly, how might we prove the safety of a visual-feedback controller? Control barrier functions (CBFs) are powerful tools for certifying the safety of feedback controllers in the state-feedback setting, but CBFs have traditionally been poorly-suited to visual feedback control due to the need to predict future observations in order to evaluate the barrier function. In this work, we solve this issue by leveraging recent advances in neural radiance fields (NeRFs), which learn implicit representations of 3D scenes and can render images from previously-unseen camera perspectives, to provide single-step visual foresight for a CBF-based controller, where the CBFs possess a discrete-time nature. This novel combination is able to filter out unsafe actions and intervene to preserve safety. We demonstrate the effect of our controller in real-time simulation experiments where it successfully prevents the robot from taking dangerous actions.

**【译文】**
为了在复杂环境中导航，机器人越来越多地需要使用高维视觉反馈（例如图像）来进行控制。然而，依赖高维图像数据来做控制决策引发了一些重要问题；特别是：我们如何证明一个视觉反馈控制器的安全性？控制屏障函数（CBF）是在状态反馈场景下为反馈控制器提供安全性保证的有力工具，但 CBF 传统上并不适用于视觉反馈控制，因为评估屏障函数需要预测未来的观测。在本工作中，我们利用神经辐射场（NeRF）的最新进展解决了这一问题。NeRF 学习三维场景的隐式表示，并能够从未见过的相机视角渲染图像，从而为基于 CBF 的控制器提供"单步视觉前瞻"能力（这里的 CBF 具有离散时间性质）。这种新颖的组合能够滤除不安全的动作并进行干预以保持安全。我们在实时仿真实验中展示了该控制器的效果：它成功地防止了机器人采取危险动作。

📌 `【注释】`

- **视觉前瞻（visual foresight）**：指机器人"在行动之前先在脑海里想象"执行某个动作之后会看到什么画面。人类开车时会预判"如果我往左打方向盘，会不会撞上护栏"；本文让机器人用 NeRF 来做同样的事情。
- **单步（single-step）前瞻**：机器人只需要预测"执行动作 u 后的下一时刻"这一张图像，而不需要预测未来许多步（多步预测计算量爆炸）。这正是 CBF 理论的优势——把"长期安全"压缩成一个"一步的约束"。
- **离散时间（discrete-time）CBF**：计算机控制的机器人是在一个个时间步（例如每秒 10 次）上运行的，而不是连续时间，因此论文使用离散时间版本的 CBF 理论（源自参考文献 [13]）。

## I. 引言与相关工作（Introduction & Related Work）

**【原文】**
Robots are increasingly making use of visual feedback to explore novel, complex environments, particularly in GPS-denied environments, and recent works have demonstrated the potential for using this visual feedback directly for control [1], [2]. However, before we can use visual data to make control decisions in safety-critical robotic systems, we must be able to certify the safety of vision-based controllers. For instance, imitation learning-based pixel controllers have been a popular way of combining control and vision [3], but lack safety guarantees, which can bring risks to the system.

**【译文】**
机器人越来越多地利用视觉反馈来探索新颖、复杂的环境，特别是在 GPS 信号被拒止（不可用）的环境中；近期的研究已经展示了直接利用这种视觉反馈进行控制的潜力 [1], [2]。然而，在安全关键的机器人系统中使用视觉数据来做控制决策之前，我们必须能够对基于视觉的控制器进行安全性认证。例如，基于模仿学习的像素控制器一直是结合控制与视觉的流行方式 [3]，但它们缺乏安全性保证，这可能给系统带来风险。

📌 `【注释】`

- **GPS 拒止环境（GPS-denied environment）**：室内、隧道、地下、洞穴等收不到 GPS 卫星信号的环境。此时机器人只能靠自身传感器（如相机）来感知和定位。
- **模仿学习（imitation learning）**：一种机器学习范式，让机器人通过模仿人类专家（如人类驾驶员）的示范数据来学习策略。它学得快，但学到的策略没有数学上的安全保证——这就是本文要解决的问题。
- **安全性认证（certify safety）**：用数学方法严格证明"无论发生什么，机器人都不会发生碰撞"，而不是仅仅靠大量实验"感觉挺安全"。

**【原文】**
Unfortunately, ensuring safety for visual-feedback controllers is a challenging problem, since this issue lies in the intersection of control theory and computer vision. To solve this problem, we bring together two powerful concepts from each of these disciplines. Control barrier functions (CBFs) are powerful tools from control theory for proving the safety of a feedback controller [4], [5]; in contrast with reachability-based approaches to safety verification [6], CBFs require us to consider only a single-step horizon, reducing computation time and allowing them to be used for real-time control. Unfortunately, CBFs typically require a known model for how control actions affect future measurements of the CBF. For systems with state feedback, such a model is often available, and approximate models are available for some types of high-dimensional observations such as Lidar [7], but the lack of a predictive model for visual feedback has so far prevented the use of CBFs in the visual-feedback setting.

**【译文】**
不幸的是，为视觉反馈控制器确保安全性是一个极具挑战性的问题，因为它处于控制理论与计算机视觉两个领域的交叉点。为了解决这个问题，我们把两个领域中各自的一个强大概念结合起来。控制屏障函数（CBF）是控制理论中用于证明反馈控制器安全性的有力工具 [4], [5]；与基于可达性分析的安全性验证方法 [6] 相比，CBF 只需要我们考虑单步时域（single-step horizon），从而减少计算时间，使其可以用于实时控制。不幸的是，CBF 通常需要一个已知的模型，来描述控制动作将如何影响 CBF 的未来测量值。对于具有状态反馈的系统，这样的模型通常是现成的；对于某些类型的高维观测（如激光雷达 Lidar）也有近似模型可用 [7]；但对于视觉反馈，由于缺乏预测模型，至今一直阻碍着 CBF 在视觉反馈场景中的应用。

📌 `【注释】`

- **可达性分析（reachability-based verification）**：另一种安全验证方法。它精确计算系统在未来所有时刻可能到达的状态集合（可达集），检查这个集合是否与障碍物相交。它精确但计算极其昂贵（"维数灾难"），难以在线实时使用。CBF 则是"退而求其次"的高效替代：不计算整个未来，只要求每一步都满足一个局部约束。
- **单步时域（single-step horizon）**：这是本文最核心的思想——CBF 把"永远安全"这个无限期约束，转化为"下一步安全且屏障值以速率 α 衰减"这样一个只需看一步的约束（见公式 (1) 与第三部分的推导）。
- **为什么状态反馈容易、视觉反馈难**：如果知道机器人状态 x（位置、速度），那么用动力学模型 f(x,u) 就能算出执行 u 之后的新状态，从而算出新的 CBF 值。但如果控制决策依据的是图像 y，就需要知道"执行 u 之后图像会变成什么样"——这需要能从任意新视角渲染场景的能力，这正是 NeRF 提供的。

**【原文】**
To close this gap, we turn to neural radiance fields (NeRFs), a recently developed technique from the computer vision community where a neural network is used to learn an implicit representation of a 3D scene [8]. NeRFs can be used to re-render a scene from a previously-unseen perspective, allowing a robot to predict the image it would observe if it were to move from its current viewpoint. Recent work on NeRF-enabled SLAM [9], [10] has shown that neural implicit scene representations can be trained online for novel environments, opening up a range of robotics applications for this technology.

**【译文】**
为了填补这一空白，我们转向神经辐射场（NeRF）——这是计算机视觉领域近年来发展出的一项技术：用一个神经网络来学习三维场景的隐式表示 [8]。NeRF 可以从一个从未见过的视角重新渲染场景，从而使机器人能够预测：如果它从当前视点移动，将会观察到什么样的图像。近期关于 NeRF 赋能的 SLAM 工作 [9], [10] 表明，神经隐式场景表示可以在线训练以适应全新的环境，为这项技术开辟了一系列机器人应用。

📌 `【注释】`

- **隐式表示（implicit representation）**：与"显式表示"（如体素网格、点云、三角形网格，用离散数据显式存储场景形状）相对。隐式表示用一个连续函数（这里是神经网络）来"隐含地"定义场景：输入一个三维坐标和观察方向，输出该点的密度和颜色。它不显式存储"哪里有墙"，但问它任何一点，它都能回答"这里是不是被物体占据"。
- **SLAM（Simultaneous Localization And Mapping，即时定位与地图构建）**：机器人在未知环境中一边移动、一边建图、一边估计自己位置的技术。传统 SLAM 建的是点云/网格地图，NeRF-SLAM 建的是"神经场地图"。

**【原文】**
Our key insight in this paper is that implicit neural scene representations (like NeRFs) can provide foresight for vision-based controllers; they allow a robot to predict the effect of its actions on future image observations, allowing it to filter out actions that produce unsafe future observations. This insight leads us to the following contributions:

1) We present a novel CBF-based controller that ensures safety for a controller operating solely on high-dimensional visual feedbacks.
2) We combine discrete-time CBFs with NeRFs to enable single-step visual foresight, allowing our controller to determine whether an action is safe or unsafe using only a single-step horizon.
3) We demonstrate that this controller can run in simulation at real-time rates (improving on previous NeRF-based works by several orders of magnitude).

**【译文】**
本文的关键洞见是：隐式神经场景表示（如 NeRF）可以为基于视觉的控制器提供前瞻能力；它们使机器人能够预测其动作对未来图像观测的影响，从而滤除那些会产生不安全未来观测的动作。这一洞见引出了以下贡献：

1) 我们提出了一种新颖的基于 CBF 的控制器，为完全依靠高维视觉反馈运行的控制器提供安全保证。
2) 我们将离散时间 CBF 与 NeRF 相结合，实现单步视觉前瞻，使我们的控制器只需单步时域即可判断一个动作是安全还是不安全。
3) 我们证明该控制器可以在仿真中以实时速率运行（相比之前的 NeRF 方法提速了若干个数量级）。

📌 `【注释】`

- **数量级（orders of magnitude）**：10 倍为一个数量级。"若干个数量级"指快了几十倍到几百倍。后文实验部分给出具体数字：对比方法 NeRF-Navigation 单步求解需要超过 80 秒，而本文方法安全动作评估只需 0.01 秒、不安全时批量评估 10 个候选动作只需 0.095 秒——相差约三个数量级（1000 倍）。
- **贡献 1 与贡献 2 的区别**：贡献 1 强调"控制器只靠图像就能安全运行"这一整体成果；贡献 2 强调技术手段——CBF（提供一步约束）+ NeRF（提供未来图像的预测）。

## II. 背景与预备知识（Background & Preliminaries）

**【原文】**
In this section we will briefly introduce NeRFs and CBFs, upon which our visual-foresight CBF controller builds.

**【译文】**
在本节中，我们将简要介绍 NeRF 和 CBF——我们的"视觉前瞻 CBF 控制器"正是建立在这两者的基础之上。

### A. 神经辐射场（Neural Radiance Fields）

**【原文】**
Neural Radiance Fields (NeRFs) are a recently-developed method to synthesize views of 3D scenes by learning a latent, continuous representation of a 3D volume. NeRFs represent a scene with a fully connected deep network that predicts the density and color of points in 3D space as a function of location and viewing direction. A NeRF is typically trained via a reconstruction loss on a series of example images, and the scene can be re-rendered from a new perspective using differentiable ray-tracing [8].

**【译文】**
神经辐射场（NeRF）是近年发展出的一种方法：通过学习三维体积的潜在（latent）连续表示来合成三维场景的新视图。NeRF 用一个全连接深度网络来表示场景，该网络以三维空间中的位置和观察方向为输入，预测这些点的密度和颜色。NeRF 通常通过在一系列示例图像上的重建损失（reconstruction loss）来训练；训练完成后，可以利用可微光线追踪（differentiable ray-tracing）从新的视角重新渲染场景 [8]。

📌 `【注释】`

- **可微光线追踪（differentiable ray-tracing）**：从相机出发，对每个像素发出一条光线穿过场景，沿途采样许多点，用网络查询每个点的密度和颜色，然后通过体积渲染（volume rendering）公式"累积"成该像素的最终颜色。整条计算链都可导，因此可以用梯度下降来训练网络参数——这就是"可微"的含义。渲染深度图同理：沿光线积分出第一个"被占据"的位置。
- **重建损失**：训练目标——让网络渲染出来的图像与真实相机拍摄的图像尽量接近（通常用均方误差等）。
- 直观理解：NeRF 相当于一个"三维场景的模拟器"。训练时给它看几张真实照片；训练好后，你问它"如果相机放在位置 P、朝方向 D 看，会看到什么？"它就能渲染出对应的照片/深度图。

**【原文】**
Recent works such as iMAP [10] and NICE-SLAM [9] have applied NeRFs to SLAM (Simultaneous Localization And Mapping) problems in robotics. By relying on a pre-trained network to warm-start the learning process, NeRFs can be fine-tuned online to represent novel environments, while simultaneously optimizing the parameters of the scene representation and the estimated camera pose allows a robot to simultaneously estimate its own position. Other works have attempted to use NeRFs as the basis for a trajectory optimization pipeline [11], but since trajectory optimization over a long horizon requires hundreds of calls to the underlying NeRF, these techniques are extremely computationally expensive.

**【译文】**
iMAP [10] 和 NICE-SLAM [9] 等近期工作已将 NeRF 应用于机器人领域的 SLAM（即时定位与地图构建）问题。通过依赖一个预训练网络来"热启动"（warm-start）学习过程，NeRF 可以在线微调以表示全新的环境；同时优化场景表示的参数与估计的相机位姿，使机器人能够同时估计自身的位置。另一些工作尝试将 NeRF 作为轨迹优化流程的基础 [11]，但由于在长时间域上进行轨迹优化需要对底层 NeRF 进行数百次调用，这些技术的计算开销极其巨大。

📌 `【注释】`

- **热启动（warm-start）**：先用大量室内场景数据预训练网络，使其"见过世面"（学会室内场景的一般规律），到达新环境时只需少量在线微调即可适配，而不是从零开始训练。
- **相机位姿（camera pose）**：相机在世界坐标系中的位置 + 朝向。
- **轨迹优化（trajectory optimization）**：规划出一条从起点到终点的完整路径/轨迹的优化问题，通常要考虑未来很多步——每一步都要反复查询 NeRF（渲染图像），所以非常慢。本文方法只需查询"下一步"。

### B. 控制屏障函数（Control Barrier Functions）

**【原文】**
Safety is a recurring problem in robotics: given a potentially nonlinear dynamical system, how can we choose control inputs to ensure that this system will remain safe? Control barrier functions (CBFs) have emerged to handle this problem analogously to how Control Lyapunov functions (CLFs) may be used to prove the stability of a control system [4], [5]. We will briefly review the theory of CBFs here; a more thorough survey can be found in [5].

**【译文】**
安全性是机器人学中反复出现的问题：给定一个可能非线性的动力学系统，我们如何选择控制输入，以确保该系统始终保持安全？控制屏障函数（CBF）就是为了处理这个问题而出现的，其地位类似于控制李雅普诺夫函数（CLF）用于证明控制系统的稳定性 [4], [5]。我们在这里简要回顾 CBF 理论；更全面的综述见 [5]。

📌 `【注释】`

- **控制李雅普诺夫函数（CLF）**：CLF 之于"稳定性"，就像 CBF 之于"安全性"。李雅普诺夫函数是一个"能量函数"，若能量持续下降，则系统稳定（收敛到目标点）。CBF 则是一个"距离/危险函数"，若危险指标被约束在不增长（甚至持续下降）的范围内，则系统永远不进危险区。
- **非线性（nonlinear）系统**：真实机器人动力学几乎都是非线性的（如四旋翼、汽车模型），比线性系统难分析得多。CBF 理论的价值就在于它对非线性系统也适用。

**【原文】**
Consider a discrete-time dynamical system with state x ∈ X ⊆ ℝⁿ and control u ∈ U ⊆ ℝᵐ, dynamics xₜ₊₁ = f(x, u), and observations in the form of w × h-size RGBd images of the robot's environment y = o(x) ∈ ℝʷˣʰˣ⁴. CBFs have been applied previously to Lidar feedback [7], but we are not aware of any other work considering the case of visual feedback without assuming access to a bounded-error state-estimation oracle [12]. Let us denote as Xᵤ ⊂ X a set of unsafe states that is disjoint from the set of admissible initial conditions X₀ ⊆ X \ Xᵤ, and let us assume that we have some function h that can distinguish between safe and unsafe states based on the observations y; i.e. h(o(x)) > 0 ⟺ x ∈ Xᵤ and h(o(x)) ≤ 0 otherwise. Further, let us assume that we have access to some nominal policy π₀(y). This nominal policy may be wildly unsafe, and so the goal of a CBF is to find some small control intervention that ensures the system remains safe.

**【译文】**
考虑一个离散时间动力学系统：状态 x ∈ X ⊆ ℝⁿ，控制 u ∈ U ⊆ ℝᵐ，动力学为 xₜ₊₁ = f(x, u)，观测为机器人环境的 w × h 尺寸 RGBd 图像 y = o(x) ∈ ℝʷˣʰˣ⁴。CBF 此前已被应用于激光雷达反馈 [7]，但据我们所知，还没有任何其他工作在不假设拥有一个有界误差状态估计"预言机"（oracle）的前提下考虑视觉反馈的情形 [12]。记 Xᵤ ⊂ X 为不安全状态集合，它与可容许初始条件集合 X₀ ⊆ X \ Xᵤ 不相交；假设我们有一个函数 h，能够基于观测 y 区分安全与不安全状态，即 h(o(x)) > 0 ⟺ x ∈ Xᵤ，否则 h(o(x)) ≤ 0。进一步假设我们有一个标称策略 π₀(y)。这个标称策略可能非常不安全，因此 CBF 的目标是找到某个**小幅控制干预**，以确保系统保持安全。

📌 `【注释】`

- **RGBd 图像**：普通彩色图（RGB）之外还带深度通道（d 表示 depth）。y ∈ ℝʷˣʰˣ⁴ 表示宽 w、高 h、4 个通道（红、绿、蓝、深度）的图像。深度图的每个像素值是该像素对应方向上最近物体表面的距离——它是判断"离墙多远"最直接的量。
- **状态估计预言机（oracle）**：指一个能"准确告诉你当前状态"的外部模块。文献 [12] 假设机器人拥有一个有界误差的状态估计器（估计误差有上限），从而把视觉问题转化成状态问题；本文则完全不假设能估计状态，直接在图像空间中定义安全。
- **标称策略（nominal policy）π₀(y)**：原本打算执行的控制指令的来源。它可以是人类遥操作（人在远程看画面、推摇杆）、强化学习策略等。安全滤波器只在该策略的指令不安全时才出手修改。
- **最小干预（minimal intervention）**：安全滤波器的哲学——"能不插手就不插手，必须插手时改动越小越好"。这样既保证安全，又尽量尊重人类/原策略的意图。

**【原文】**
The key result from CBF theory [13] is that this safety-preserving control action can be found by solving the optimization problem:

**【译文】**
CBF 理论的关键结论 [13] 是：这个保持安全的控制动作可以通过求解如下优化问题得到：

**【公式 (1)：CBF-QP 优化问题】**

```
u* = arg min  ‖u − π₀(yₜ)‖²                        (1a)
        u
     s.t.   h ∘ o ∘ f(xₜ, u) ≤ α · h ∘ o(xₜ)       (1b)
```

**【原文】**
where ∘ denotes function composition and α ∈ (0, 1) is a rate-determining constant. If a feasible u can always be found, then h is a valid CBF and acts as a certificate to prove the safety of the control system. In this case, h can be used to "filter" any potentially unsafe input, as may arise in a reinforcement learning or human teleoperation context.

**【译文】**
其中 ∘ 表示函数复合，α ∈ (0, 1) 是一个决定衰减速率的常数。如果总能找到可行的 u，则 h 是一个有效的 CBF，并作为证明控制系统安全性的"证书"（certificate）。在这种情况下，h 可用来"过滤"任何潜在不安全的输入——例如强化学习或人类遥操作场景中可能产生的输入。

📌 `【注释】`

- **函数复合 h∘o∘f(xₜ, u)**：从里向外读——f(xₜ, u) 是用动力学模型预测的"执行 u 之后的下一状态"；o(·) 是该状态对应的观测图像；h(·) 是该图像对应的危险值。所以约束 (1b) 的左边就是"执行动作 u 后，机器人将会处于多危险的境地"。
- **"证书"（certificate）**：数学上指一个能证明系统满足某性质的"证明文件"（一个满足特定条件的函数）。CBF 就是安全性证书：只要存在 CBF 且每步约束都满足，就能严格推出"系统永远安全"（推导见本文档第三部分）。
- **α 的含义**：若当前 h 值为负（安全），约束 (1b) 要求下一步的 h 值不超过 α × 当前值。由于 0 < α < 1 且当前 h ≤ 0，有 α·h ≥ h，所以下一步的 h 值最多可以"回升"到 α 倍当前值 —— 可以从负值往上爬，但仍不许越过 0。**α 越小 → 允许回升到的位置越靠近 0 → 约束越松（滤波器可以等到最后一刻才动手，代价是干预又急又猛）；α → 1 → 约束退化为 $h_{t+1} \le h_t$，要求每步都不许更危险 → 约束最紧。**
  > ⚠️ **本条为仓库版修正**：原文此处曾写成"α 越小……更保守；α 越接近 1 越宽松"，方向反了，且与本文档第三部分（"α 很小时约束很松"）以及论文图 5b 的实验结论（α 小 → 最大干预更大）互相矛盾。以推导为准，详见 [`02_学习路线与讲义.md`](02_学习路线与讲义.md) 第五、六讲。

**【原文】**
Of course, since the constraint (1b) requires predicting the image o∘f(xₜ, u) that would be observed if the robot were to take action u, CBFs have not previously seen much use in the direct visual-feedback setting. Some papers make promising steps towards understanding the case where visual feedback is used to for state estimation alongside a traditional state-feedback controller [12], but in this paper we attempt to solve the more challenging problem where the CBF and controller are defined directly in the space of visual observations. The main issue that arises when defining the CBF as a function of state is poor generalization. Previous works have shown that CBFs defined as functions of state do not generalize well to new environments (e.g. when obstacles have moved), whereas CBFs defined as functions of observations are naturally conditioned on the observed state of the environment [7].

**【译文】**
当然，由于约束 (1b) 要求预测"机器人采取动作 u 之后将会观测到的图像" o∘f(xₜ, u)，CBF 此前在直接视觉反馈场景中应用甚少。有些论文在"视觉反馈与传统的状态反馈控制器并用、用于状态估计"的情形上迈出了有希望的步伐 [12]；但在本文中，我们尝试解决更具挑战性的问题：将 CBF 和控制器直接定义在视觉观测空间中。把 CBF 定义为状态函数的主要问题是泛化性差。已有研究表明：定义为状态函数的 CBF 难以泛化到新环境（例如障碍物移动之后），而定义为观测函数的 CBF 天然地以"观测到的环境状态"为条件，因而泛化更好 [7]。

📌 `【注释】`

- **泛化（generalization）**：把在环境 A 中学到的安全知识搬到环境 B 的能力。基于状态的 CBF 学到的往往类似"在坐标 (3,5) 处要刹车"——环境一变、墙挪了位置就完全失效；基于观测的 CBF 学的是"画面里离墙多近就该刹车"——这种知识不依赖具体坐标，换个房间照样管用。这是本文把 CBF 定义在图像空间的关键动机。
- **直接定义在视觉观测空间**：意味着安全函数 h 的输入是图像 y 而不是状态 x，控制器全程不需要"知道自己在哪"。

## III. 问题陈述与假设（Problem Statement & Assumptions）

**【原文】**
Our goal in this paper is to adapt the CBF safety filter framework described in Eq (1a) and [4], [5], [13] for use in the visual-feedback setting. Here, we state the control objectives and assumptions used throughout our paper.
As the robot navigates its environment, it builds an implicit scene representation in the form of a NeRF (which is partly pre-trained to enable fast adaptation). As the robot explores, the controller must ensure safety, i.e. avoiding any collisions with the environment. To achieve this goal using a safety filter like Eq. (1a), the filter must be able to tell whether an intended control action will bring the robot dangerously close to any nearby obstacle. If the intended action is found to be unsafe, the filter must find the smallest control intervention that still preserves safety. Formally, these requirements are:

1) **Safety**: the robot must remain a sufficient distance from any obstacles visible nearby; i.e. given an RGBd image y ∈ ℝʷˣʰˣ⁴, min(0≤i≤w; 0≤j≤h) y[i, j]_depth > d_c, where d_c > 0 is the minimum safe clearance.
2) **Minimal intervention**: the safety filter should minimize any deviation from the nominal control policy, insofar as is possible without violating the safety requirement. This requirement is naturally captured by the CBF-QP with objective (1a) and constraint (1b).

**【译文】**
本文的目标是把式 (1) 以及 [4], [5], [13] 中描述的 CBF 安全滤波器框架适配到视觉反馈场景中。下面陈述全文使用的控制目标和假设。
机器人在环境中导航时，以 NeRF 的形式构建一个隐式场景表示（该 NeRF 经过部分预训练以实现快速适配）。在机器人探索的过程中，控制器必须保证安全，即避免与环境发生任何碰撞。为了用式 (1a) 这样的安全滤波器实现这一目标，滤波器必须能够判断：某个拟执行的控制动作是否会让机器人危险地接近任何邻近障碍物。如果该拟执行动作被判定为不安全，滤波器必须找到**仍能保持安全的最小控制干预**。形式上，这些要求为：

1) **安全性**：机器人必须与附近可见的任何障碍物保持足够距离；即给定 RGBd 图像 y ∈ ℝʷˣʰˣ⁴，要求 min(0≤i≤w; 0≤j≤h) y[i, j]_depth > d_c，其中 d_c > 0 是最小安全间隙。
2) **最小干预**：在不违反安全性要求的前提下，安全滤波器应尽可能减小与标称控制策略的偏差。这一要求天然地由目标函数 (1a) 和约束 (1b) 所构成的 CBF-QP 所刻画。

📌 `【注释】`

- **min_{i,j} y[i,j]_depth**：遍历深度图的所有像素，取最小值——也就是"画面里离相机最近的障碍物有多远"。它是"当前离碰撞有多远"的直接度量。
- **最小安全间隙 d_c**：允许的最小距离阈值（实验中取 0.1 m、0.5 m、0.9 m 等）。要求"最近障碍物距离 > d_c"即"永远不要进入距任何障碍物 d_c 以内的区域"。
- **CBF-QP**：QP = Quadratic Program（二次规划），指目标函数是二次函数、约束是线性/仿射不等式的一类优化问题，可以极快地求解。式 (1a) 目标 ‖u − π₀(yₜ)‖² 是 u 的二次函数，所以叫 CBF-QP。它是 CBF 领域最常用的安全滤波器实现形式（经典文献 [4]）。
- **"最小干预"如何体现在公式里**：目标函数 (1a) 让滤波器选出的 u 尽可能接近原指令 π₀(yₜ)；约束 (1b) 保证所选 u 不会让下一时刻变得危险。两者合起来就是"在保证安全的前提下尽量少干预"。

**【原文】**
We note that our definition of safety is limited to what can be observed by the robot via its cameras, so we do not consider the case when a robot can collide with an obstacle in its blind spot. This is an important case that deserves additional study, but it is outside the scope of this paper; we focus only on the case when safety can be defined purely as a function of the robot's observations. We also note that our approach can be easily extended to the case when the robot has multiple cameras, so covering these blind spots would be as simple as adding additional cameras in practice.

**【译文】**
我们指出，本文对安全的定义仅限于机器人通过相机所能观测到的内容，因此我们不考虑机器人与视线盲区中的障碍物碰撞的情形。这是一个重要且值得进一步研究的情形，但超出了本文的范围；我们只关注"安全可以纯粹定义为机器人观测的函数"的情形。我们还指出，我们的方法可以很容易地扩展到机器人拥有多台相机的情形，因此在实际中，覆盖这些盲区只需增加额外的相机即可。

📌 `【注释】`

- **盲区（blind spot）**：相机视野（field of view）之外的区域。例如单目前视相机看不到身后的墙，若机器人倒退就可能撞上。论文坦承这一局限，并给出实用解法：加相机（每个相机对应一张待渲染图像）。

**【原文】**
Finally, we would like to design our safety filter so that it can be easily adapted to robots with different dynamics. To do this, we will make use of a two-level control architecture, inspired by other works on formal methods for robot safety [14], [15]. In this architecture, we apply our visual-feedback safety filter at the top level with a simplified model of the robot's dynamics (e.g. a single- or double-integrator or a Dubins car), then use a low-level controller to track the top-level state using the full nonlinear dynamics of the system. Several techniques exist for deriving lower-level controllers with guaranteed tracking bounds [14], [16], and so we focus on deriving a CBF visual-feedback safety filter for the high level controller with simplified plant dynamics (the error bound of the tracking controller determines the safety margin d_c in our framework, ensuring that safety is still maintained).

**【译文】**
最后，我们希望设计的这个安全滤波器能够方便地适配具有不同动力学的机器人。为此，我们采用一个**两层控制架构**，其灵感来自其他关于机器人安全形式化方法的工作 [14], [15]。在该架构中，我们在顶层对机器人动力学的**简化模型**（例如单积分器、双积分器或 Dubins 小车）应用我们的视觉反馈安全滤波器；然后用一个**底层控制器**，以系统的完整非线性动力学去跟踪顶层状态。已有多种技术可以推导出具有保证跟踪误差界限的底层控制器 [14], [16]，因此我们专注于为使用简化对象动力学的顶层控制器推导一个 CBF 视觉反馈安全滤波器（跟踪控制器的误差界限决定了我们框架中的安全裕量 d_c，从而确保安全性仍然成立）。

📌 `【注释】`

- **两层架构（two-level architecture）**：顶层用简单模型做"决策"（往哪走、走多快），底层用真实复杂模型做"执行"（如何调电机电压去实现）。这是控制工程中的经典分层思想：顶层简单→便于做安全证明；底层复杂→负责搞定真实物理。
- **单积分器（single integrator）**：动力学为 ẋ = u（或离散形式 xₜ₊₁ = xₜ + u·Δt）。你可以把它理解为"直接控制速度"的模型：给什么速度指令，位置就按什么速度变化。
- **双积分器（double integrator）**：动力学为 ẍ = u。你可以理解为"直接控制加速度"的模型（如质量-弹簧或点质量小车）。
- **Dubins 小车（Dubins car）**：只能前进、有最小转弯半径的车模型（类似汽车，不能横移）。
- **保证跟踪误差界限（guaranteed tracking bound）**：底层跟踪控制器承诺"真实状态与顶层期望状态之间的误差不超过某个已知上限 ε"。那么只要顶层保证"距障碍物 > d_c"，并取 d_c ≥ ε，真实机器人就仍然不会撞墙——误差被安全裕量吸收了。
- **"简化模型 + 误差裕量"是形式化安全领域的标准套路**：用简单模型做证明，用误差裕量兜底，参考文献 [14]（FaSTrack）是这套方法的代表作。

## IV. 方法（Approach）

**【原文】**
We will first provide an overview of our control architecture, then provide more detail on the two main subsystems: the observation-space CBF used to maintain safety and the NeRF used to predict future values of that CBF.

**【译文】**
我们首先概述控制架构，然后详细介绍两个主要子系统：用于保持安全的观测空间 CBF，以及用于预测该 CBF 未来取值的 NeRF。

### A. 概述（Overview）

**【原文】**
The algorithm for our discrete-time visual CBF safety filter is provided in Algorithm 1, and the interaction between the neural-implicit scene representation (for which we use the NICE-SLAM implementation [9]) and the CBF is illustrated in Fig. 1. Algorithm 1 proceeds as follows: first, the most recent observation is used to update both the state estimate and neural scene representation using the NICE-SLAM subsystem [9]. Then we predict the next state and observation given the nominal control input uₜ = π₀(yₜ) using the dynamics and neural scene representation, respectively. We then use the CBF to decide whether this control action is safe; if it is, we accept this control action, but if it is not we re-sample randomly in the vicinity of uₜ to find new candidate control actions. In practice, instead of re-sampling control actions one-at-a-time if the nominal policy is unsafe, we evaluate multiple candidate interventions in parallel to speed execution time and find a safe candidate close to the nominal control action.

**【译文】**
我们的离散时间视觉 CBF 安全滤波器算法见算法 1，神经隐式场景表示（我们使用 NICE-SLAM 的实现 [9]）与 CBF 之间的交互如图 1 所示。算法 1 的流程如下：首先，利用 NICE-SLAM 子系统 [9]，用最新的观测同时更新状态估计和神经场景表示。然后，在给定标称控制输入 uₜ = π₀(yₜ) 的情况下，分别用动力学模型和神经场景表示预测下一状态和下一观测。接着，我们用 CBF 判断该控制动作是否安全；若安全则接受该动作；若不安全，则在 uₜ 附近随机重采样，寻找新的候选控制动作。在实践中，若标称策略不安全，我们不是逐个重采样控制动作，而是**并行评估多个候选干预**，以加快执行速度，并找到一个接近标称控制动作的安全候选。

**【算法 1：视觉前瞻 CBF 安全滤波器】**（论文原文为伪代码，此处逐行翻译）

```
算法 1  视觉前瞻 CBF 安全滤波器。θₜ 表示神经场景表示的模型参数，
        它们在每个时间步被微调。
输入:   图像 yₜ，标称策略 π₀，NeRF 参数 θₜ₋₁
  u₀, u ← π₀(yₜ)，safe ← FALSE                        ▷ 取标称控制指令
  θₜ, x̂ₜ ← NSUpdate(yₜ, θₜ₋₁)                        ▷ 更新模型与状态
  while not safe do                                   ▷ 循环直到找到安全动作
      x̂ₜ₊₁ ← f(x̂ₜ, u)                                ▷ 预测下一状态
      ŷₜ₊₁ ← NSPredict(x̂ₜ₊₁, θₜ)                     ▷ 预测下一观测（渲染图像）
      hₜ ← h(yₜ)，hₜ₊₁ ← h(ŷₜ₊₁)                     ▷ 计算 CBF 值
      if hₜ₊₁ ≤ α·hₜ then
          safe ← TRUE，return u, safe                 ▷ 满足 CBF 约束 → 接受 u
      else
          safe ← FALSE，u ← Re-Sample(u₀)            ▷ 否则在 u₀ 附近重新采样
      end if
  end while
```

📌 `【注释】`

- **NSUpdate**：对应 NICE-SLAM 的"建图（mapping）+ 跟踪（tracking）"两步——用新图像更新 NeRF 场景模型 θ，同时更新对机器人自身位姿的估计 x̂ₜ。
- **NSPredict**：从估计的下一状态（位姿）出发，让 NeRF 渲染出"机器人移动到那里会看到的图像" ŷₜ₊₁。
- **Re-Sample(u₀)**：在标称指令 u₀ 附近按高斯分布采样新候选动作（实验部分说明采样分布为 N(0, I)，批量 10 个并行评估）。这是一种简单的随机搜索，用来近似求解式 (1) 的优化问题（找到离 u₀ 近且满足约束的动作）。
- **算法核心判断 `hₜ₊₁ ≤ α·hₜ`**：这正是公式 (1b)。只要每个时间步都满足它，就能用归纳法证明永远安全（见第三部分推导）。
- **为什么"评估 CBF 要预测图像"**：h 定义在图像上，所以要知道执行 u 后是否安全，必须先"看见"执行 u 后的图像——这就是 NeRF 的用武之地。

**【图 1 图注翻译】**

**【原文】**
Fig. 1: The NeRF-enabled safety filter used in our control architecture. The NICE-SLAM subsystem [9] is used to predict future RGBd observations using a neural implicit representation of the scene, and a CBF uses those predictions to decide if a control action is safe. If the intended control action is unsafe, our algorithm searches for nearby control actions that are safe (not shown, but described in Algorithm 1).

**【译文】**
图 1：我们的控制架构中所用的"NeRF 赋能的安全滤波器"。NICE-SLAM 子系统 [9] 利用场景的神经隐式表示来预测未来的 RGBd 观测，CBF 则利用这些预测来判断某个控制动作是否安全。如果拟执行的控制动作不安全，我们的算法会搜索附近安全的控制动作（图中未展示，但算法 1 中已有描述）。

### B. 视觉控制屏障函数（Visual Control Barrier Functions）

**【原文】**
The CBF h(y) : ℝʷˣʰˣ⁴ ↦ ℝ is used to ensure that the system remains safe. In order to be useful, a CBF must not only distinguish safe (h < 0) and unsafe (h > 0) situations, but it must also generalize well to new environments. This need for generalization is our key motivation for defining the CBF as a function of observations. Previous work [7] has shown that observation-space CBFs generalize much better than state-based CBFs; the intuition is that if an obstacle moves in the scene, then previously-safe states may become unsafe, but an image of the obstacle will usually be a reliable indicator of how far away it is.

**【译文】**
CBF h(y) : ℝʷˣʰˣ⁴ ↦ ℝ 用于确保系统保持安全。为了发挥作用，CBF 不仅要能区分安全情形（h < 0）与不安全情形（h > 0），还必须能很好地泛化到新环境。这种泛化需求正是我们把 CBF 定义为观测函数的关键动机。此前的工作 [7] 已表明：观测空间中的 CBF 比基于状态的 CBF 泛化性好得多。直观解释是：如果场景中的障碍物移动了，那么"以前安全的状态"可能变得不安全；但障碍物的图像通常是"它有多远"的可靠指示器。

📌 `【注释】`

- 注意符号约定：本文中 **h < 0 表示安全、h > 0 表示不安全**（h = 0 是安全边界）。这与摘要前文的约定一致（h(o(x)) > 0 ⟺ 不安全）。初学者容易与某些 CBF 文献中"h ≥ 0 为安全集"的约定混淆——两种约定都存在，阅读时务必注意每篇论文的具体约定。

**【原文】**
In keeping with our use of a two-layer control architecture, as discussed in Section III, we will define a CBF for two common simplified dynamics models, the single- and double-integrators, which we can then combine with a lower-level tracking controller to ensure the safety of robots with a wide range of possible dynamics [14], [15]. When using first-order dynamics, we use the CBF h(y) = d_c − min(i,j) y[i, j]_depth. When using second-order dynamics, we can augment the CBF with an estimate of the robot's velocity: h(y, v̂) = d_c − min(i,j) y[i, j]_depth + β‖v̂‖ where β > 0 is an empirically-tuned hyperparameter. This CBF allows the robot to extrapolate and intervene to modify the control action even when collision is not imminent (we observe empirically in Section V-B that the CBF will often gradually increase its intervention as the robot approaches an obstacle).

**【译文】**
与第三节讨论的两层控制架构一致，我们为两种常见的简化动力学模型——单积分器与双积分器——分别定义 CBF，然后将其与底层跟踪控制器结合，以确保具有各种可能动力学的机器人的安全 [14], [15]。使用一阶动力学时，我们采用的 CBF 为 h(y) = d_c − min(i,j) y[i, j]_depth。使用二阶动力学时，我们可以用机器人速度的估计来增强 CBF：h(y, v̂) = d_c − min(i,j) y[i, j]_depth + β‖v̂‖，其中 β > 0 是经验性调优的超参数。这个 CBF 使机器人能够"外推"（提前预判）并在碰撞尚未来临时就干预、修改控制动作（我们在第 V-B 节的实验中经验性地观察到：随着机器人接近障碍物，CBF 往往会逐渐加大干预力度）。

📌 `【注释】`

- **一阶 CBF 的含义**：h = d_c −（画面中最近障碍物的距离）。当最近距离 > d_c 时 h < 0（安全）；距离 = d_c 时 h = 0（到达安全边界）；距离 < d_c 时 h > 0（不安全）。它只用当前画面，不管速度。
- **二阶 CBF 中的速度项 +β‖v̂‖**：h 随速度增大而增大。也就是说，即使离墙还远（min depth 大），只要冲得快（‖v̂‖ 大），h 也可能 > 0，滤波器就会提前干预减速。这就是"外推（extrapolate）"的含义——用速度预测"照这样冲下去，等到了墙边就刹不住了"。v̂ 是速度的估计值（可由状态估计器提供）。
- **β 的作用**：β 越大，速度对危险值的贡献越大，机器人越早开始刹车（越保守）。论文实验取 β = 1。
- **为什么二阶需要速度项**：双积分器控制的是加速度，单看"距离"时系统可能已经来不及刹车（惯性的作用），必须在危险值里提前计入速度因素。

### C. 神经隐式场景表示与状态估计（Neural Implicit Scene Representation and State Estimation）

**【原文】**
Our safety filter in Algorithm 1 relies on the ability to not only estimate the robot's position and build a representation of the scene (NSUpdate) but also predict what observations the robot could receive if it were to take a particular action (NSPredict). We rely on recently-developed NeRF-based tools for both of these functions. In particular, we integrate the NICE-SLAM (Neural Implicit Scalable Encoding for SLAM) framework presented in [9] into our safety filter. The core of NICE-SLAM is a set of pre-trained NeRFs that are retrained online to build a representation of the scene as the robot explores. Since NeRF rendering is differentiable, NICE-SLAM is able to optimize both the parameters of its NeRFs (the mapping step) and an estimate of the robot's pose (tracking); NSUpdate refers to both the mapping and tracking steps.

**【译文】**
算法 1 中的安全滤波器依赖于两项能力：不仅能够估计机器人的位置并构建场景表示（NSUpdate），还要能够预测机器人采取某个特定动作后将会接收到什么样的观测（NSPredict）。这两项功能我们都借助了最近开发的基于 NeRF 的工具。具体来说，我们将 [9] 中提出的 NICE-SLAM（Neural Implicit Scalable Encoding for SLAM，面向 SLAM 的神经隐式可扩展编码）框架集成到我们的安全滤波器中。NICE-SLAM 的核心是一组**预训练的 NeRF**，它们在机器人探索过程中被在线重训练，以构建场景表示。由于 NeRF 渲染是可微的，NICE-SLAM 能够同时优化其 NeRF 的参数（建图步骤，mapping）和机器人位姿的估计（跟踪步骤，tracking）；NSUpdate 指的就是建图与跟踪这两个步骤。

📌 `【注释】`

- **NICE-SLAM**：苏黎世联邦理工（ETH）等机构提出的高效 NeRF-SLAM 系统，用多个小型 NeRF 网格 + 特征网格实现快速训练与渲染，是 2022 年 CVPR 论文。本文直接"拿来"当作感知前端。
- **建图（mapping）**：更新场景模型参数 θ，让场景表示越来越准确。
- **跟踪（tracking）**：把当前相机位姿当作优化变量，让"NeRF 从该位姿渲染出的图像"与"真实相机图像"尽量一致，从而反推相机在哪。
- **预训练的意义**：从零训练一个 NeRF 通常要几小时，无法在线使用；预训练 + 微调让在线建图成为可能。

**【原文】**
NICE-SLAM is also able to predict the RGBd image the robot would likely observe if it were to move to a new pose in the environment by simply re-rendering the NeRF from the new viewpoint (NSPredict). This capability allows the robot to imagine what observations it would receive as a result of taking different actions, so the robot can proactively determine whether an action would be unsafe and avoid it. Calls to NSPredict can be easily batched and parallelized on GPU to reduce the time needed to execute Algorithm 1.

**【译文】**
NICE-SLAM 还能够在机器人移动到环境中的新位姿时，通过简单地从新视角重新渲染 NeRF（NSPredict）来预测机器人可能观测到的 RGBd 图像。这一能力让机器人能够"想象"采取不同动作后将会接收到什么观测，从而主动判断某个动作是否会不安全并避开它。对 NSPredict 的调用可以方便地在 GPU 上批量化和并行化，以减少算法 1 的执行时间。

📌 `【注释】`

- **"想象"（imagine）**：NeRF 充当机器人的"心理模拟器"。评估 10 个候选动作 = 渲染 10 张图像，可以在 GPU 上并行做，所以批量评估 10 个候选动作只需 0.095 秒（实验部分的数据）。

## V. 实验（Experiments）

**【原文】**
In this section, we present experimental results to characterize our proposed safety filter, justify its key design decisions, and understand the effect of hyperparameters on controller performance. We compare our controller with the NeRF-Navigation framework, which maintains safety by solving a trajectory optimization problem using the point-wise density of the NeRF scene representation as a proxy for collision cost. To our knowledge, NeRF-Navigation is the only other published work using NeRFs for robot motion control, but we find that it has several performance and reliability issues. Although our work and NeRF-Navigation have different goals (safety filter vs trajectory planning), it is still useful to compare against another NeRF-based approach.

**【译文】**
在本节中，我们给出实验结果，以刻画我们所提出的安全滤波器的特性、论证其关键设计决策的合理性，并理解超参数对控制器性能的影响。我们将我们的控制器与 NeRF-Navigation 框架进行比较——后者通过求解一个轨迹优化问题来维持安全，它使用 NeRF 场景表示的逐点密度作为碰撞代价的代理（proxy）。据我们所知，NeRF-Navigation 是唯一一个已发表的、使用 NeRF 进行机器人运动控制的工作，但我们发现它存在若干性能与可靠性问题。尽管我们的工作与 NeRF-Navigation 的目标不同（安全滤波器 vs 轨迹规划），但与其他基于 NeRF 的方法进行比较仍然是有价值的。

📌 `【注释】`

- **NeRF-Navigation**：参考文献 [11]（"Vision-Only Robot Navigation in a Neural Radiance World"，RA-L 2022），用 NeRF 密度场做轨迹优化。它是本文的对比基线。
- **逐点密度作为碰撞代价的代理（proxy）**：把"该位置是否被物体占据"用"该位置的 NeRF 密度值"来近似。密度高 → 可能被占据 → 碰撞代价高。本文第五章 C 节证明了这种近似不可靠。
- **安全滤波器 vs 轨迹规划**：前者不生成完整路径，只是逐时刻地"批准/修改"外部给出的指令；后者要规划一条完整轨迹。两者用途不同，但都是"用 NeRF 做运动控制"，故可比。

### C. 消融研究（Ablation Study）

**【原文】**
Our proposed CBF safety filter relies on the rendered RGB and depth images from the NeRF, rather than using the underlying NeRF density field as a proxy for collision likelihood (as NeRF-Navigation does). The NeRF density refers the probability of a point terminating a ray of light, whereas depth is determined by integrating along a ray originating at a camera. In this section we justify our decision to rely on depth by showing that a CBF based on density alone does not preserve safety; we believe this is because the density field is not a consistent proxy for collisions.

**【译文】**
我们所提出的 CBF 安全滤波器依赖 NeRF 渲染出的 RGB 和深度图像，而不是像 NeRF-Navigation 那样把底层的 NeRF 密度场当作碰撞可能性的代理。NeRF 密度指的是"一个点终止一条光线的概率"，而深度是通过沿相机发出的光线积分确定的。在本节中，我们通过展示"仅基于密度的 CBF 无法保持安全"来论证我们选择依赖深度的决策；我们认为这是因为密度场并不是碰撞的一致（consistent）代理。

📌 `【注释】`

- **消融研究（ablation study）**：通过"去掉系统的某个组件，观察性能变化"来验证该组件价值的实验方法。这里"切除"的是深度渲染，换成密度场，证明深度必不可少。
- **NeRF 密度**：NeRF 网络对每个 3D 点输出一个体积密度 σ。它刻画该点"对光线的衰减能力"——密度大的地方光线容易被截断，因此常被近似当作"被占据"。但严格来说它是渲染拟合出来的中间量，不一定与真实几何形状一致（这正是后文的发现）。
- **深度**：沿像素光线积分，找到密度积累到阈值的距离。它更直接地对应"相机到这个方向最近表面有多远"。

**【原文】**
To conduct this comparison, we define a density-based CBF h(x̂) = d_c + σ(x̂), where σ(x̂) is the NeRF density at the location implied by state x̂. Density is positive and tends to increase in occupied regions of space, so we set d_c to a negative value determined by measuring the density near the walls; note that d_c no longer directly refers to a physical safety margin in this setting. Fig. 6a shows the performance of a density-based CBF controller with d_c = −30; we see that this CBF does not intervene even as the distance between the robot and the wall drops to 0. This behavior appears to be caused by a lack of a clear dependence between NeRF density and distance to the walls. We also test d_c = −40 (finding a similar result) and d_c = −20 (unable to find a safe control action by solving Eq. (1a)).

**【译文】**
为了进行这一比较，我们定义一个基于密度的 CBF：h(x̂) = d_c + σ(x̂)，其中 σ(x̂) 是状态 x̂ 所蕴含位置处的 NeRF 密度。密度为正，且在空间中被占据的区域趋于增大，因此我们将 d_c 设置为一个负值——通过测量墙壁附近的密度来确定；注意，在这一设定下 d_c 不再直接对应物理意义上的安全裕量。图 6a 展示了 d_c = −30 的密度 CBF 控制器的性能；我们看到，即使在机器人与墙的距离降为 0 时，这个 CBF 也没有干预。这一行为似乎是因为 NeRF 密度与"到墙的距离"之间缺乏清晰的依赖关系。我们还测试了 d_c = −40（结果类似）和 d_c = −20（无法通过求解式 (1a) 找到安全控制动作）。

**【原文】**

## VI. 讨论与局限性（Discussion & Limitations）

**【原文】**
In this paper, we present a novel CBF-based controller that ensures safety for a controller operating solely on high-dimensional visual feedback. We combine CBFs with NeRFs to enable single-step visual foresight, allowing our controller to determine whether an action is safe or unsafe using only a single-step horizon. In comparison with previously-published NeRF-based motion controllers, which cannot run in real-time and can be overly conservative, our controller can run in simulation at real-time rates and maintains safety while limiting the magnitude of its control intervention.

**【译文】**
在本文中，我们提出了一种新颖的基于 CBF 的控制器，为完全依靠高维视觉反馈运行的控制器提供安全保证。我们将 CBF 与 NeRF 相结合以实现单步视觉前瞻，使控制器只需单步时域即可判断一个动作安全与否。与先前发表的、无法实时运行且可能过度保守的基于 NeRF 的运动控制器相比，我们的控制器能够在仿真中以实时速率运行，并在限制控制干预幅度的同时保持安全。

**【原文】**
Our work in this paper also presents a number of drawbacks that point to interesting directions of future work. On a practical level, the most crucial point for future work is the acceleration in search of safe actions. Our method can evaluate at most 10 control actions during each step (in order to meet a 10 Hz control frequency requirement). This time is driven largely by the time needed to render depth images from the NeRF; improvements in the ability to optimize NeRFs (even at the expense of resolution) would help our method consider more candidate actions at each step. A second important step for future research is the development of vision-based CBFs for more complex dynamics, for instance by using neural networks to adapt NeRF-based CBFs for new dynamics (as [7] explores in the context of Lidar-based CBFs). Furthermore, although our method can adapt to a limited field of view by adding additional cameras, this would increase the computation time as more images would need to be rendered per step. Consequently, more work is needed to understand how to apply our technique in a limited-computation setting, perhaps by reducing the required image resolution. In future work, we also hope to explore transferring our method from desktop hardware (where it can run in real time) to common embedded platforms such as the Nvidia Jetson. On a theoretical level, our approach in this paper ignores reconstruction error in the NeRF scene representation, which may negatively impact safety; future work should also explore combining NeRF error bounds (potentially derived from statistical learning theory) with error-robust CBFs [12] to provide more solid safety guarantees.

**【译文】**
本文的工作还存在若干不足，它们指向了有趣的未来研究方向。在实践层面，未来工作最关键的一点是**加速对安全动作的搜索**。我们的方法在每个时间步最多只能评估 10 个控制动作（以满足 10 Hz 控制频率的要求）。这段时间主要由从 NeRF 渲染深度图像所需的时间决定；如果能改进 NeRF 的优化/渲染效率（即使以牺牲分辨率为代价），将有助于我们的方法在每个时间步考虑更多的候选动作。未来研究的第二个重要方向是为更复杂的动力学开发基于视觉的 CBF，例如使用神经网络让基于 NeRF 的 CBF 适配新的动力学（正如 [7] 在激光雷达 CBF 的背景下所探索的那样）。此外，虽然我们的方法可以通过增加相机来适应受限的视野，但这会增加计算时间，因为每个时间步需要渲染更多图像。因此，还需要更多工作来理解如何在有限算力的场景中应用我们的技术，或许可以通过降低所需的图像分辨率。在未来的工作中，我们还希望探索把我们的方法从桌面级硬件（可在其上实时运行）移植到常见的嵌入式平台（如 Nvidia Jetson）。在理论层面，本文的方法忽略了 NeRF 场景表示中的**重建误差**，这可能会对安全性产生负面影响；未来的工作还应探索将 NeRF 误差界（可能由统计学习理论推导得出）与误差鲁棒 CBF [12] 相结合，以提供更坚实的安全性保证。

📌 `【注释】`

- **重建误差（reconstruction error）**：NeRF 渲染出的深度图与真实深度并不完全一致（模型近似误差、训练不充分等）。本文把渲染结果当作"真实"，所以安全性证明建立在"预测准确"的假设上。若渲染误差大，机器人可能"以为安全其实危险"。未来方向：量化 NeRF 的误差上界（error bound），把它并入 CBF 约束（误差鲁棒 CBF，参考文献 [12]），使证明在渲染不完美时依然成立。
- **Nvidia Jetson**：英伟达的嵌入式 AI 计算平台（如 Jetson Xavier/Orin），常用于机载机器人。把桌面 GPU 上的方法搬上去，是走向真实机器人的一步。
- **每步 10 个候选动作的由来**：10 Hz → 每步 0.1 秒预算；批量渲染 10 张深度图约 0.095 秒 → 预算内最多评估 10 个。候选越多，找到的"安全且贴近原指令"的动作越好。

⚠️ `【勘误】` 原文 "we also youhope to explore" 中的 "youhope" 是笔误，应为 "hope"（我们未来也希望探索……）。

# 第二部分 重点名词注释（术语详解）

按主题分组，供初学者系统学习。

## 1. 安全与控制理论（Safety & Control Theory）

### 1.1 安全性（Safety）

在控制论语境中，"安全性"不是泛指，而是有严格数学定义的性质：系统状态**永远**不进入危险区域 Xᵤ（例如"与障碍物距离小于 d_c"的区域）。安全的反面是"可达集与危险集相交"。

### 1.2 控制屏障函数（CBF, Control Barrier Function）

- **通俗理解**：一个"危险值"函数 h。h ≤ 0 表示安全，h > 0 表示危险。CBF 方法不直接禁止机器人进入危险区，而是**约束危险值的演化速度**：要求每一步的危险值增长都不超过某个上限（离散情形下即式 (1b)）。就像开车时"限速 + 车距"规则——不规定你走哪条路，只规定你不能让车距小于某个值。
- **与惩罚函数（penalty/cost）的区别**：惩罚函数把"离障碍物近"变成目标函数中的一项（软约束），只是"倾向"避开，不提供硬保证；CBF 是**硬约束**（必须满足的不等式），满足则安全有严格证明。
- **连续 vs 离散**：连续时间 CBF 的经典形式是 ḣ(x) ≥ −α·h(x)（导数形式）；离散时间版本（文献 [13]）是 h(xₜ₊₁) − h(xₜ) ≥ −(1−α)·h(xₜ)，整理即 h(xₜ₊₁) ≤ α·h(xₜ)。本文用离散版本，因为机器人控制是逐时间步执行的。

### 1.3 控制李雅普诺夫函数（CLF, Control Lyapunov Function）

安全性的"表亲"。李雅普诺夫函数 V 类似"能量"，若每步能量都在减少（Vₜ₊₁ ≤ Vₜ），系统最终收敛（稳定）。CBF 保证"不进入坏区域"，CLF 保证"到达好区域（目标）"。二者可以结合成 CBF-CLF-QP，同时保证安全与收敛（本文只用 CBF，因为导航指令来自外部）。

### 1.4 安全滤波器（Safety Filter）

一个"把关"模块：接收任意来源的控制指令（人类遥操作、强化学习、模仿学习……），输出一个"安全的"控制指令。它不生成任务目标，只负责拦截危险指令。本文的算法 1 就是一个安全滤波器。

### 1.5 最小干预（Minimal Intervention）

安全滤波器的设计原则：输出的指令要尽量接近输入指令（式 (1a) 的目标函数），只在必要时做最小修改。好处：最大化尊重原策略/人类意图，避免"安全但什么都不让做"的过度保守。

### 1.6 CBF-QP（二次规划）

目标为二次函数（‖u − π₀(y)‖²）、约束为仿射不等式（式 (1b)，当 h 的复合函数对 u 近似仿射时）的优化问题。QP 是凸优化中最成熟的一类，有极快的求解器（微秒到毫秒级），适合实时控制循环。注意：本文实际不显式调用 QP 求解器，而是用"随机采样 + 检查约束"来近似求解（因为 h∘o∘f 是 NeRF 渲染，不可写成 u 的显式公式）。

### 1.7 可达性分析（Reachability Analysis）

精确计算系统未来可能到达的状态集合的方法。安全验证时检查可达集与障碍物是否相交。优点：精确、完备；缺点：计算量随状态维数指数增长（维数灾难），对图像这种超高维观测无能为力。CBF 是它的"轻量替代"——牺牲完备性换实时性。

### 1.8 两层控制架构（Two-level Control Architecture）

顶层：用简化模型（单/双积分器、Dubins 车）做安全决策；底层：用真实非线性动力学跟踪顶层输出，并保证跟踪误差有界。安全证明只需在简单模型上完成，误差界由安全裕量 d_c 吸收。代表工作：FaSTrack [14]。

### 1.9 单积分器 / 双积分器（Single / Double Integrator）

- 单积分器：ẋ = u，离散化后 xₜ₊₁ = xₜ + u·Δt。"积分器"指位置是速度的积分。控制 u 直接是速度，最简单的一阶模型。
- 双积分器：ẍ = u，即先对 u 积分得速度，再积分得位置。控制 u 是加速度，模拟惯性系统（不能瞬间停下）。阶数越高越难保证安全（因为要提前"预见"惯性），所以二阶 CBF 里加了速度项。

## 2. 计算机视觉与神经辐射场（Computer Vision & NeRF）

### 2.1 神经辐射场（NeRF, Neural Radiance Fields）

用一个多层感知机（MLP）表示三维场景：输入 3D 坐标 (x, y, z) 与视线方向 (θ, φ)，输出该点的体积密度 σ 和颜色 c。渲染时对每个像素发一条光线，沿光线采样点、查询网络，用体积渲染公式积分出像素颜色。训练：最小化渲染图与真实图的差异。核心价值：**连续、可微、紧凑的 3D 场景表示，支持任意新视角渲染**。本文把 NeRF 当作"给机器人做梦境的引擎"——想象执行动作后的画面。

### 2.2 隐式表示（Implicit Representation）

不显式存储"表面在哪里"，而是存储一个函数 f(p)（如占用概率、有符号距离、密度），通过查询判断空间任意点的属性。对比显式表示：体素网格（规则、费内存）、点云（离散、无拓扑）、网格（建图难）。隐式表示分辨率不受网格限制（连续函数），天然可微，便于优化。

### 2.3 可微渲染 / 可微光线追踪（Differentiable Rendering / Ray-tracing）

渲染过程写成可导计算图，使"渲染图像"对"场景参数、相机位姿"可求导。这是 NeRF 能训练、NICE-SLAM 能同时优化位姿与场景的根本原因——梯度可以反向传播穿透"渲染"这一过程。

### 2.4 体积密度（Volume Density）与深度（Depth）

- 密度 σ(p)：光线在 p 点被"挡住"的概率密度。理想情况下物体内部密度高、空气密度≈0。
- 深度：沿光线找到"第一个密度显著的点"的距离。渲染深度图 = 对每条光线积分求期望深度。
- 本文关键实验发现：**NeRF 的密度场并不可靠**（网络为了拟合图像可以摆出各种"奇怪"的密度分布），因此不能拿密度当碰撞指标；而渲染深度图受图像重建损失直接监督，与真实几何更一致，是更可靠的安全指标。

### 2.5 NeRF-SLAM / NICE-SLAM / iMAP

把 NeRF 用于 SLAM：用 NeRF 当"地图"，一边渲染对比真实图像来定位（跟踪），一边更新网络参数来建图。iMAP（ICCV 2021）首开先河；NICE-SLAM（CVPR 2022）用多个小型特征网格 + 解码器，训练和渲染都快得多，达到可实时级别。本文直接集成 NICE-SLAM 作为感知前端（NSUpdate / NSPredict 两个函数）。

### 2.6 RGBd 图像

RGB（红绿蓝三通道彩色）+ Depth（每像素深度）共 4 通道的图像。深度可通过 RGB-D 相机（如 Kinect、RealSense）或从 NeRF 渲染获得。本文控制决策只用深度通道（min depth），RGB 仅用于展示。

### 2.7 SLAM（Simultaneous Localization And Mapping，即时定位与地图构建）

机器人在未知环境中同时做两件事：构建环境地图、在地图中定位自己。"鸡生蛋"问题——建图要知道自己在哪，定位需要地图——因此需联合优化。传统方案建点云/网格图，NeRF-SLAM 建神经场图。

## 3. 机器学习相关（Machine Learning）

### 3.1 标称策略（Nominal Policy）π₀

"本来要执行"的控制策略，是安全滤波器的输入。可以是：人类遥操作、强化学习策略、模仿学习策略、运动规划器。论文实验用"模拟人类遥操作"（最坏情况：油门踩死冲向墙）。

### 3.2 模仿学习（Imitation Learning）

从专家示范中学习策略的范式（行为克隆是其中最简单的一种）。优点是无需奖励函数设计；缺点是分布漂移、无安全保证——这正是本文要"补"的短板。

### 3.3 泛化（Generalization）

模型在新环境/新条件下的表现。本文核心论点之一：**观测空间 CBF 泛化性优于状态空间 CBF**。原因：观测（图像）天然携带环境信息，学到的"离墙多近要刹车"与环境无关；状态空间 CBF 学到的"在坐标 X 要刹车"换环境即失效。

### 3.4 超参数（Hyperparameter）

训练/算法运行前人为设定的参数（本文的 d_c、α、β），不随数据自动学习。参数扫描（Parameter Sweep）实验研究它们的影响。

### 3.5 消融研究（Ablation Study）

验证"某组件是否有用"的实验范式：去掉组件 A 看性能是否下降。本文消融掉"深度渲染"，换成"密度场 CBF"，证明密度不可靠、深度渲染必不可少。

### 3.6 统计学习理论（Statistical Learning Theory）

研究学习算法泛化误差上界的理论。未来工作方向：用它推导 NeRF 重建误差的界，与误差鲁棒 CBF 结合（见 1.7 节、文献 [12]），补上"渲染不完美时的安全证明"。

## 公式汇总一览

| ------ | ----------------------------------------------- | -------------------- |

| (1b)   | h∘o∘f(xₜ, u) ≤ α·h∘o(xₜ)                        | 约束条件：单步危险值衰减（CBF 核心） |

## 公式 (1a) 逐符号解读

u* = arg minᵤ ‖u − π₀(yₜ)‖²

- **arg minᵤ**："使得后面表达式最小的 u 是哪个"，即优化变量是控制指令 u。
- **‖u − π₀(yₜ)‖²**：候选指令 u 与标称指令 π₀(yₜ) 之间欧氏距离的平方。平方是为了让目标函数是二次函数（凸、易优化），且不改变最小值位置。
- **整体含义**：在满足约束 (1b) 的所有指令中，挑"与原指令最像"的那个。
- **等价于最小化 ‖u − π₀‖**：开根号不改变最小值位置，所以目标就是"最小干预"。
- **若无约束**：最优解就是 u = π₀(yₜ)（滤波器完全放行）——这正是"指令本来安全时"的情形，此时算法 1 第一步就通过检查、直接返回。

## 公式 (1b) 逐符号解读

h ∘ o ∘ f(xₜ, u) ≤ α · h ∘ o(xₜ)

- **f(xₜ, u)**：动力学预测——当前状态 xₜ 执行 u 后的下一状态 xₜ₊₁。
- **o(·)**：观测模型——该状态对应的图像。
- **h(·)**：CBF——该图像对应的危险值。
- **复合读法**：h∘o∘f(xₜ, u) = h( o( f(xₜ, u) ) ) = "执行 u 之后，机器人下一时刻的危险值"（记作 hₜ₊₁）。
- **右边**：h∘o(xₜ) = h(yₜ) = 当前时刻的危险值（记作 hₜ）。
- **整体含义**：所选动作必须使危险值满足 hₜ₊₁ ≤ α·hₜ。

## 公式 (1b) 的安全性推导（论文隐含的证明，此处补全）

这是本文最重要的"推导"，原文只用一句话带过（"If a feasible u can always be found, then h is a valid CBF..."），初学者往往看不出为什么 (1b) 能保证安全。下面逐步推导：

**第 1 步：建立符号与前提。**

- 记第 t 步的危险值 zₜ = h(yₜ) = h(o(xₜ))。
- 安全条件约定：zₜ ≤ 0 表示安全，zₜ > 0 表示危险（论文约定，h(o(x)) ≤ 0 ⟺ 状态安全）。
- 前提 1（初始安全）：x₀ ∈ X₀ ⊆ X \ Xᵤ，即 z₀ = h(o(x₀)) ≤ 0。
- 前提 2（每步可满足）：对每个时间步，都能找到 u 满足 (1b)，且机器人实际执行该 u。

**第 2 步：归纳证明"所有时刻都安全"。**

由前提 2，每步执行的控制都满足：
zₜ₊₁ ≤ α·zₜ，α ∈ (0, 1)  （★）

对 t = 0：z₁ ≤ α·z₀。
因为 z₀ ≤ 0（初始安全）且 α > 0，所以 α·z₀ ≤ 0，故 z₁ ≤ 0。
（注意：α·z₀ ≥ z₀ 当 z₀ ≤ 0——α 小于 1 意味着负值"往回缩"，但 z₁ 仍被压在 ≤ 0 之内。）

假设 zₖ ≤ 0 成立，则由（★）得 zₖ₊₁ ≤ α·zₖ ≤ 0。
由数学归纳法：**对所有 t ≥ 0，zₜ ≤ 0**。

**第 3 步：翻译回物理意义。**
zₜ ≤ 0 即 h(yₜ) ≤ 0，由 h 的定义（h(o(x)) > 0 ⟺ x ∈ Xᵤ），状态 xₜ ∉ Xᵤ——机器人任何时刻都不在危险集合里，即**永远不会碰撞**。∎

**直观解释：**
(1b) 相当于给危险值装上一条"不许上涨"的规则：每过一步，危险值最多只能达到当前值的 α 倍。既然从 ≤ 0 出发，乘上正数 α 后仍然 ≤ 0，危险值就永远翻不到正数那边去。CBF 的巧妙之处在于：**它不要求预测遥远的未来**，只需保证"下一步不越过那条衰减线"，安全就自动递推到永远——这就是"单步时域"能替代"无限时域"的数学根据。

**补充说明：α 越接近 1 会发生什么？**
当 α → 1，(1b) 变成 zₜ₊₁ ≤ zₜ：危险值不允许增长。仍是安全的，但约束更紧，要求每步都"不更危险"。当 α 很小时约束很松（允许负值大幅回升），滤波器可以"等到最后一刻再动手"，但代价是干预会又急又大（实验图 5b 证实）。α 本质上调节"干预的提前量"与"干预的平滑度"之间的权衡。

## 各 CBF 公式的解读与"推导"

### 3.1 一阶 CBF：h(y) = d_c − min_{i,j} y[i,j]_depth

**如何"推导"出这个式子？** 从安全性要求 1 出发：

- 安全要求：min_{i,j} y[i,j]_depth > d_c，即最近障碍物距离必须大于安全裕量。
- 我们的约定是"h ≤ 0 表示安全"。把这个不等式改写为"某函数 ≤ 0"的形式：
  min depth > d_c ⟺ d_c − min depth < 0（严格不等式，取极限即 ≤ 0）。
- 因此令 h(y) = d_c − min_{i,j} y[i,j]_depth，则 h ≤ 0 ⟺ 最近距离 ≥ d_c，恰好符合 CBF 的符号约定。**这就是该公式的全部"推导"**——它不过是用 CBF 记法重写了安全条件本身。

**性质：**

- 当最近距离 = d_c 时 h = 0，即安全边界。
- h 的变化直接对应"接近障碍物（h 上升）或远离（h 下降）"。
- 只依赖深度图，不需要状态、不需要环境知识，因此**天然跨环境泛化**。

### 3.2 二阶 CBF：h(y, v̂) = d_c − min_{i,j} y[i,j]_depth + β‖v̂‖

**为什么要加速度项？（推导思路）**

- 双积分器系统有惯性：即使当前距离还远，高速逼近时也需要提前减速，否则刹不住。
- 只用距离的 CBF（3.1 式）会等到距离接近 d_c 才干预，那时加速度控制已来不及——CBF 约束 (1b) 可能无解（找不到任何 u 使 hₜ₊₁ ≤ α·hₜ）。
- 把速度的惩罚 β‖v̂‖ 加进危险值：速度越大，h 越大，等效于"把危险提前"。滤波器会在速度贡献使 h 逼近 0 时就提前减速。
- **β 的物理含义**：速度项的"汇率"——把 1 m/s 的速度折算成多少米的风险距离。β 越大，系统越早、越温和地干预。
- 注意：论文原句说 "augment the CBF with an estimate of the robot's velocity"（用速度的估计 v̂），说明该 CBF 需要从状态估计器获得 v̂（两层架构中顶层状态估计提供）。

**为什么是 ‖v̂‖（速度的范数）而不是 v̂ 本身？** 因为危险程度只与"冲得有多快"有关，与方向无关（任何方向高速移动都危险）。范数取模长，方向信息被丢弃。

### 3.3 密度 CBF：h(x̂) = d_c + σ(x̂)（消融实验中的对照组）

- 结构：与 3.1 完全同构——"阈值 d_c + 危险量 σ(x̂)"。
- 符号差异：σ ≥ 0 且"越危险越大"，所以用加法（而距离是"越大越安全"，用减法）；为保证 h ≤ 0 表示安全，d_c 取负值（论文中 d_c = −30、−40、−20）。
- **失败的原因（论文的实证结论）**：σ 与真实几何距离之间缺乏稳定、单调的对应关系（图 6b 显示墙边密度不高）。因此无论阈值调大调小都无法正确工作：
  - d_c = −20（阈值太严）：处处危险，式 (1a) 无可行解，机器人"瘫痪"；
  - d_c = −30、−40（阈值太松）：撞墙时 h 仍 < 0，滤波器"失明"。
- **教训**：安全指标必须与实际碰撞风险有单调、可预测的关系；NeRF 密度不满足此要求，而渲染深度满足。

### 3.4 实验指标公式

- **干预量 Δu = ‖u − π₀(y)‖**：直接度量"滤波器修改指令的幅度"。实验曲线中 Δu = 0 表示放行；Δu > 0 表示出手。图 3a 中 Δu 在机器人逼近墙时才从 0 升起——最小干预原则的实证。
- **最小间隙 d_min = min_{i,j} y[i,j]_depth**：每步记录画面中最近障碍物距离，是"是否安全"的最终裁判。图 3–6 都画它。图 5a 显示 d_min ≈ d_c——验证 CBF 让机器人"贴着安全边界但不越过"。

## 算法 1 与公式 (1) 的对应关系

| 算法 1 的步骤                     | 对应的数学含义                                            |
| ---------------------------- | -------------------------------------------------- |
| u₀, u ← π₀(yₜ)               | 候选解初始化：先试标称指令（它使目标函数 (1a) 达到理论最小值 0）               |
| θₜ, x̂ₜ ← NSUpdate(yₜ, θₜ₋₁) | 更新场景模型 θ 与状态估计 x̂ₜ（提供公式中的 xₜ 与 o、f 所需的场景）          |
| x̂ₜ₊₁ ← f(x̂ₜ, u)            | 计算 f(xₜ, u)：动力学一步预测                                |
| ŷₜ₊₁ ← NSPredict(x̂ₜ₊₁, θₜ)  | 计算 o(x̂ₜ₊₁)：NeRF 渲染预测图像（NeRF 扮演观测模型 o）             |
| hₜ ← h(yₜ)，hₜ₊₁ ← h(ŷₜ₊₁)    | 计算 h∘o(xₜ) 与 h∘o∘f(xₜ, u)：约束 (1b) 两边的值             |
| if hₜ₊₁ ≤ α·hₜ then return u | 检查约束 (1b) 是否满足；满足 → 该 u 是式 (1) 的可行解，且因最贴近 π₀ 而近似最优 |
| else u ← Re-Sample(u₀)       | 不满足 → 在 u₀ 附近随机采样下一个候选，继续搜索可行解（随机化近似求解 QP）         |

**为什么用"随机采样"而不是解 QP？** 经典 CBF-QP 要求 h∘o∘f(xₜ, u) 能写成 u 的显式函数（通常是仿射）才能快速求解。但本文中 o 是 NeRF 渲染（深度神经网络），无法写出解析表达式，也无法求梯度（其实可求，但每步渲染+反传成本高），所以用"采样 10 个候选 + 逐个渲染验证"的随机搜索近似。采样点在 u₀ 附近 → 找到的解自然接近 π₀ → 近似满足目标函数 (1a)。这是"模型复杂到无法显式优化"时的工程折中。

## 一条完整的"安全链"（把全文串起来的思维导图）

1. 相机拍到当前图像 yₜ → NICE-SLAM 更新场景模型与位姿（NSUpdate）。
2. 人类/策略给出指令 π₀(yₜ)（可能危险）。
3. 用动力学 f 预测"执行 u 后机器人在哪"；用 NeRF 渲染"在那里会看到什么"（NSPredict）→ 得到预测深度图。
4. CBF h 把预测深度图翻译成一个危险值 hₜ₊₁。
5. 检查 hₜ₊₁ ≤ α·hₜ：满足 → 放行；不满足 → 换个候选指令重复 3–4。
6. 归纳证明保证：只要每步都满足第 5 步，h 永远 ≤ 0，机器人永远不碰撞。

**一句话总结全文**：*CBF 把"永远安全"压成"一步约束"，NeRF 负责在图像空间中评估这一步约束，二者结合让纯视觉控制器首次获得了可实时运行的安全保障。*
